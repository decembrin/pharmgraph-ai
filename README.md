# PharmGraph AI

PharmGraph AI is an AI-powered agent for exploring pharmaceutical knowledge graphs using FalkorDB.

The project focuses on **Evidence-Based Graph Reasoning** — autonomous exploration of relationships between medications, active ingredients, drug interactions, and adverse effects, with explainable conclusions backed by medical sources.

## Hackathon

Developed for [Graph Hacks: Context for AI Agents](https://www.wemakedevs.org/hackathons/falkordb), organized by WeMakeDevs and FalkorDB (October 15–18, 2026).

**Track 01:** Agents That Act on Connected Data.
